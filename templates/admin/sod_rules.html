What is SoD? Segregation of Duties prevents one person from holding two roles that together create a security or fraud risk — e.g. the same person having both Finance access and Security audit access could conceal fraudulent activity. When a rule exists, the system blocks any role assignment that would create that combination, and writes a SOD_VIOLATION_BLOCKED entry to the audit log.
